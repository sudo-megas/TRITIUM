### 2.2 Toolchain

- `npm init`; **Electron latest stable at the moment of scaffolding, pinned
  exact** in `package.json` (record the number in the F1 PUTAG commit message).
- electron-vite, electron-builder, React 19, react-dom, zustand, i18next,
  react-i18next, smol-toml, TypeScript `strict: true`, ESLint, Prettier,
  vitest, @playwright/test.
- npm scripts in the JADEITE naming: `dev`, `build`, `audit`, `start`,
  `typecheck`, `test`, `test:unit`, `test:watch`, `test:e2e`.
- `build` and `test` run `audit` first and fail on any audit failure.

### 2.3 The four audit scripts — armed from day one

| Script | Fails the build when… |
|---|---|
| `audit-egress` | any of `fetch(`, `XMLHttpRequest`, `net.`, `http.`, `https.`, `WebSocket`, `navigator.sendBeacon` appears in `src/` |
| `audit-strings` | a user-visible string literal sits in a `.tsx` outside the i18n JSON files |
| `audit-colours` | a colour literal (`#hex`, `rgb(`, `hsl(`) appears outside `palettes.css` |
| `audit-locale` | `navigator.language`, `Intl.DateTimeFormat()` -without-explicit-locale, or `app.getLocale` appears anywhere |

These are copies of the JADEITE pattern, rewritten for this tree — not shared code.

### 2.4 The shell

- One `BrowserWindow`: minimum **1280 × 720**, native frame (the compositor
  decorates), no remembered geometry logic.
- **Top tab bar over two big panes** — the XTRITIUM §7 frame. F1 ships the frame with
  provisional tabs: `SUMMARY · FUEL · COSTS · SERVICE · CHARTS · STATISTICS ·
  SETTINGS · ABOUT` (names and count are design-phase property; the *bar* is F1's).
  Every pane except Settings and About is an empty two-pane placeholder —
  empty cells, no "get started" screens, per XTRITIUM §7.
- **Settings (working subset):** language switch (en ⇄ tr, manual, instant) and
  palette switch (11 entries, placeholder colours). Persisted to
  `~/.local/share/tritium/settings.toml` through **the atomic write helper**
  (temp + fsync + rename) — the helper is written here, unit-tested here, and
  becomes the only write path for every later milestone.
- **About (complete):** the family cult layout — the mark, the maker, version
  v0.1.0, release date, source address, licence in full. Addresses selectable,
  never clickable. About is finished in F1 and only its version number changes
  afterwards.
- **CaskaydiaCove Nerd Font Mono** bundled and applied globally; one Font
  Awesome glyph rendered from the font patch to prove the icon path.
- i18next wired: `en` default, `tr` complete for every string the F1 shell shows.

### 2.5 Tests that must exist

- vitest: atomic-write helper (torn-write simulation: kill between temp and
  rename, assert old file intact) · settings round-trip through smol-toml ·
  schema_version stamp present.
- Playwright: app launches → tab bar renders all tabs → language switch flips a
  visible string → palette switch changes a computed CSS variable → About shows
  the licence → window refuses to shrink below 1280 × 720.
- `npm run audit` passes clean on the F1 tree.

## 3. SCOPE — OUT

No data layer beyond `settings.toml`. No vehicles, no entries, no charts, no
statistics. No PKGBUILD (F13). No README beyond the stub (F14). No icon artwork —
`build/icon/` stays empty until the maker supplies PNGs. No design decisions —
placeholder palettes carry obviously-wrong colours on purpose so nobody mistakes
them for the design phase's output.

## 4. ACCEPTANCE CRITERIA

F1 is done when every line below is true:

1. `npm install && npm run dev` opens the shell on a clean Arch machine with
   only `nodejs` and `git` present.
2. `npm run build` completes; audits run first and pass.
3. `npm test` is green: all §2.5 units and e2e.
4. `npx tsc --noEmit` is silent under `strict: true` for all three tsconfigs.
5. The window will not shrink below 1280 × 720; the compositor draws the frame.
6. Language toggles en ⇄ tr instantly and persists across a restart via
   `settings.toml`.
7. Palette switch changes the UI instantly and persists the same way.
8. `settings.toml` on disk is valid TOML, carries `schema_version = 1`, and
   survives a kill-mid-write with the previous version intact.
9. About is complete per XTRITIUM §10; nothing in the app opens a browser.
10. Zero network: the audit proves it statically, and a Playwright run with all
    network access blocked behaves identically to one without.
11. No AI attribution exists anywhere in the tree or the git history.

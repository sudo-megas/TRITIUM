# TRITIUM — F12 · v0.2.2 · «Hardening»

Repo path of this file: `~/REPO/build/docs/F12.md`
Governing document: `~/REPO/XTRITIUM.md` — where this file and XTRITIUM disagree, XTRITIUM wins.

Eleven milestones have each ended with a list of acceptance criteria, and some
of those lines have been checked by a person reading them rather than by
anything that fails. F12 is the milestone that turns the honest ones into gates
and finds out whether the rest are true.

`build/docs/issues.md` is the brief. Fifteen defects have been recorded, and F12
asks of each: **could a gate have caught this, and if so, why is there no gate?**
Two answers came back with real work attached, and both are in scope below.

The other half is the edge cases. Every milestone tested the path it built; F12
tests the paths nobody meant to build — an empty list where a figure was
expected, a file the maker edited badly, a figure larger than the app was
imagined for.

## 2. SCOPE — IN

### 2.1 The decisions this milestone settles

1. **Two acceptance criteria become audits.**

   Every milestone from F4 onward carries the line *"`writeFileSync` appears
   nowhere in `src/` outside `atomic.ts`"* — eight documents asserting it, and
   nothing checking it. §4.1's atomic write is the promise that a power cut
   yields the old file or the new one and never a torn one, and it is worth
   exactly as much as the guarantee that nothing bypasses it.

   And two of the recorded defects — I-01 and I-02 — are the same defect twice:
   a write path in the main process that told no other window it had written.
   F5 found the first, fixed it, and **wrote the second one down** so F6 would
   inherit rather than rediscover it. That worked. A gate would have meant it
   never happened twice.

   So `scripts/audit-storage.mjs` joins the five: no `writeFileSync` outside
   `atomic.ts`, and **every `ipcMain.handle` that reaches a repository write
   must broadcast**.

2. **Prettier stops being decorative — for code, and not for prose.**
   `issues.md` I-09: `prettier --check` fails on forty files, most untouched by
   any recent milestone, and nothing runs it. A formatter nobody runs is not a
   convention, it is a file in the repository.

   F12 formats the **code** — `.ts`, `.tsx`, `.css`, `.json` — once, and adds
   `--check` to the audit chain so it stays true.

   **Markdown is excluded, by `.prettierignore`, deliberately.** XTRITIUM is the
   constitution and the F-documents are its record; both are hand-set, wrapped
   where the sentences want to break, and reflowing them to a printWidth would
   destroy an authorship the project has maintained for twelve milestones. The
   formatter serves the code; the prose is the maker's.

3. **The edge cases are the ones nobody built for.** Each milestone tested the
   path it added. F12 tests what happens at the edges of those paths — and where
   the answer is already right, the test is still worth having, because it is
   the answer that must not change quietly:

   - a record file the maker damaged in Neovim
   - figures far larger than a car — a seven-figure odometer, a million-lira fill
   - a vehicle whose every optional field is empty
   - `settings.toml` with every unit at the non-default, then read back
   - an empty payment-method list (§3.8 — he meant it)
   - a date at a year boundary, a leap day, and the turn of a month
   - unicode in every text field, including the Turkish letters slugs remove

4. **A defect found here is fixed here, and recorded.** F12 is allowed to change
   behaviour where a test proves it wrong. Anything found goes into `issues.md`
   with the rest, which is the file that made this milestone possible.

5. **No new dependency, no new feature, no new file format.** Hardening that
   added surface would be a contradiction.

### 2.2 Tests that must exist

- **vitest:** the two new audit rules, against fixtures that violate them and
  fixtures that do not — the same shape `tests/unit/audits.test.ts` already uses
  for the other five · every edge case of decision 3 that can be asked of a pure
  function.
- **Playwright:** the edge cases that need a window — a damaged file reported
  and left alone, a seven-figure odometer that does not overflow its column,
  every unit at the non-default surviving a restart.
